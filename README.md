# GUI's Arc v6.2 Site Schedule & Split Guides

v6.2 패치입니다.

## 핵심
- 현장스케줄은 기록만 합니다.
- 오늘의 안전가이드는 스케줄/날씨/장비에서 안전 항목만 읽습니다.
- 오늘의 현장가이드는 공사/품질/자재 항목만 읽습니다.
- 건설사고 브리핑은 포스터형 사고사례 뉴스 카드로 표시합니다.
