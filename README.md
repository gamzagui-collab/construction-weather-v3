# GUI's Arc v6.0.1

건설현장 날씨·안전·작업가이드 안정 개선판입니다.

## 적용

1. 기존 프로젝트 백업
2. `.git` 폴더는 유지
3. ZIP 내용을 덮어쓰기
4. `git add .` → `git commit` → `git push`
5. `worker/worker.js`를 Cloudflare Worker에 배포


## v6.2 Integrated
- 탭 구조 분리: 강수 예보 / 온도·안전관리 / 오늘의 안전가이드 / 오늘의 현장가이드 / 현장스케줄 / 건설사고 브리핑
- 현장스케줄 달력형 기록
- 자재·장비 반입 기록을 안전가이드와 현장가이드에 자동 반영
- 건설사고 브리핑 포스터형 카드


## v6.2 Final
- TBM 전달문 흰색 글자 버그 수정
